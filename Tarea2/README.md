# Catálogo Interactivo de Elementos de UI

## Descripción

Catálogo interactivo de componentes de interfaz de usuario, implementado en tres tecnologías distintas para comparar los componentes básicos de una interfaz móvil, sus equivalencias entre plataformas y las diferencias entre enfoques de construcción de interfaces.

**Tecnologías utilizadas:**
- Android nativo con Views y XML
- Android nativo con Jetpack Compose
- Flutter (Dart)
